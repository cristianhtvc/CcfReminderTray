# 会议截稿提醒（CcfReminderTray）

Windows 11 系统托盘小工具：固定关注六个 AI 会议主会常规论文的**摘要注册 / 全文提交**截止，右键托盘图标看倒计时，临近截止发桌面通知。无需管理员权限，无后台服务。

固定关注的六个会议：**ICML、ICLR、NeurIPS、AAMAS、AAAI、DAI**（DAI 指 International Conference on Distributed Artificial Intelligence）。

## 数据来源与核验状态（重要）

- 全部会议数据来自 ccfddl 社区聚合项目发布的
  `https://ccfddl.com/conference/allconf.json`，外加本机最近一次有效缓存。
- ccfddl 是社区维护的聚合信息，**本应用未逐项对照各会议官网核验**。界面与通知中均标注“来源 ccfddl，未逐项核验”。
- 若时间有冲突，**一律以当届会议官方网站 / 官方投稿页面为准**。重要的截稿时间请务必自行核对官网。
- 上游许可：MIT（Copyright (c) 2021 CCFDDL），完整版权与许可文本见同目录 `THIRD-PARTY-NOTICES.txt`。

## 通知与提醒的边界（请阅读）

- 桌面通知是否弹出横幅由 **Windows 通知开关**与**“请勿打扰”**等系统设置控制；应用在系统关闭通知时无法让横幅出现。
- **应用未运行时不会提醒**：没有后台守护进程，关机、退出或崩溃期间跨过的档位，只在下次启动后按规则补一次最紧迫档。
- **每个本地日最多一条汇总通知**。因此存在如实告知的限制：若当天名额已用掉，**当天新出现或改期的紧急截止当天不会再次提醒；若该节点当天即截止，次日它已过期，可能完全不再提醒**。重要时间请以会议官网为准。
- 仅提醒主会常规轨道的摘要注册 / 全文提交；rebuttal、录用通知、特殊 track、身份不明或时间不可信的节点不提醒（可在详情窗查看）。

## 手动修正截止时间

当某届官网时间与 ccfddl 数据不一致时，你可以手动修正（以当届官网为核验依据）：

1. 托盘菜单 → **查看全部**，选中一个**主会常规**的**摘要注册 / 全文提交**节点，
   点 **修正此节点…**（rebuttal、录用通知、特殊轮次与身份不明节点不开放修正；
   同一节点在上游出现多个候选时按钮禁用，以免修正套错对象）。
2. 输入修正后的时间并**显式选择时区**（本地时区 / AoE / UTC±N / PT 等），
   填写**修正依据**与**修正来源**（如当届官网链接），两者必填。
   点“换算预览”先核对 UTC 与本地换算结果；保存前需再确认一次。
   夏令时切换造成的“不存在的本地时间”或“出现两次的歧义时间”会被明确拒绝并解释，
   应用不会替你猜测，请改用 UTC±N 形式指定。
3. 保存后：托盘菜单倒计时、详情窗与提醒统一改用修正后的有效时间，菜单行标注
   “· 已修正”；详情行保持选中，底部面板立即给出三方对照
   （**修正时上游值／最新上游值／你的修正值**）以及依据、来源与修正时间。
4. **恢复上游值**：选中已修正节点点该按钮即可删除修正，菜单与提醒立即按上游时间重算。
5. 上游后续变化时**不会覆盖你的修正**：上游改期或改写时区，对应行标注
   “已修正·上游已变化”并在面板给出三方差异；上游删除该节点时修正保留在
   “已修正·上游已找不到对应节点”分组（可查看或恢复），但在节点重新出现前不作为
   有效时间使用；同一键出现多个候选时修正保留但暂不应用。
6. 修正单独保存在 `overrides.json`（见下节“数据存放位置”），不改写上游缓存。
   若该文件损坏：启动时醒目告警、程序按上游时间运行、阻止任何写入以免覆盖你已有的
   修正；详情窗底部提供“备份损坏文件并重新初始化”——它先把损坏文件**复制**为
   `*.corrupt-*.bak` 留证（原件不动），再重建空修正表；备份中的修正需人工查看后重新录入。

## 安装与卸载

> **未签名说明**：当前安装包与 exe 均未做代码签名。首次运行时 Windows 可能显示
> SmartScreen 应用信誉提示（“Windows 已保护你的电脑”一类）。这是未签名个人软件的
> 常见现象；是否继续由你按自己的安全策略判断，本文不提供关闭或绕过系统安全保护的步骤。

### 安装版（CcfReminderTray-Setup-x.y.z.exe，推荐）

1. 运行安装程序，安装到当前用户目录 `%LOCALAPPDATA%\Programs\CcfReminderTray\`（固定当前用户安装，不需要管理员权限，不提供切换安装模式的选项）。
2. 从“开始”菜单启动，或勾选安装结束页的“运行”。
3. 卸载：Windows“设置 → 应用 → 已安装的应用”中找到“会议截稿提醒”卸载。卸载程序会：
   - 若应用正在运行，提示你先从托盘正常退出后再继续（**提示并阻止继续，不会自动关闭进程**，也不会触碰其他目录的同名程序）；
   - 清理开机启动项前先核对：仅当 HKCU Run 中的 `CcfReminderTray` 值**指向本次安装目录的 exe** 时才删除；若它已指向其他位置（如便携版），则保留不动；
   - 然后**询问是否保留**你的个人数据（`%LOCALAPPDATA%\CcfReminderTray\`，含设置、
     提醒状态、数据缓存、你手动修正的截止时间 `overrides.json` 及损坏修正备份
     `*.corrupt-*.bak`）——由你选择，不会静默删除。**选择删除即删除整个目录，手动修正
     与备份删除后无法恢复**；该目录与便携版共享，删除对两者同时生效（见“数据存放位置”）。

### 便携版（CcfReminderTray-portable-x.y.z-win-x64.zip）

1. 解压到一个**固定位置**。若你也使用安装版，请选一个**与安装版不同**的目录
   （建议 `%LOCALAPPDATA%\Programs\CcfReminderTray-portable\`；安装版固定使用
   `%LOCALAPPDATA%\Programs\CcfReminderTray\`）。**不要把便携版解压进安装版目录**：
   卸载安装版会删除该目录下的程序文件，你的便携副本会一并消失。
   双击 `CcfReminderTray.exe` 运行。通知区域出现图标；若被收入隐藏区，按应用内一次性提示自行固定。
2. **手动卸载步骤**：
   1. 右键托盘图标 → 设置 → 查看“开机启动”：
      - 若设置窗**没有**“另一位置已有启动项”的提示且该项已勾选 → **取消勾选并保存**
        （这会清除指向当前这份副本的开机启动项）；
      - 若设置窗提示“另一位置已有启动项” → 该启动项不属于本副本，取消勾选保存**不会**
        删除它；如确要清除，请先勾选“开机启动”并保存（把启动项切换为本副本），再取消
        勾选并保存（此时才会删除），或按提示到对应那份程序里操作；
   2. 右键托盘图标 → **退出**（图标消失、进程结束）；
   3. 删除解压目录；
   4. 如需清除个人数据，删除 `%LOCALAPPDATA%\CcfReminderTray\`。该目录含设置、提醒状态、
      数据缓存、**手动修正 `overrides.json` 及其损坏备份 `*.corrupt-*.bak`**，删除后无法恢复；
      它与安装版共享，删除后安装版同样丢失上述全部内容。
3. 顺序无关紧要的只有第 3、4 步；第 1 步若跳过，注册表会留下一个指向已删除路径的 `CcfReminderTray` 值（无害，可在 `HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run` 手动删除）。

### 移动 exe 位置后（两种形式都适用）

开机启动项记录的是 exe 的绝对路径。**移动程序位置后，请打开“设置”重新勾选“开机启动”并保存一次**，路径才会更新为新位置。
若旧路径已失效、你想**彻底清除**该启动项：取消勾选保存**不会**删除指向旧路径的值
（为避免误删其他副本，取消保存只清除指向当前程序的启动项）。准确的清除步骤是：
先勾选“开机启动”并保存（启动项切换为当前程序路径），再取消勾选并保存（此时值指向
当前程序，会被删除）；或在 `HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run`
中手动删除 `CcfReminderTray` 值。

## 自包含单文件的说明

便携版与安装版内的 exe 均为 .NET 10 自包含单文件，**不依赖机器上安装 .NET 运行时**。首次或更新后启动时，Windows 可能把少量原生组件提取到临时目录（`%TEMP%` 下的 `.net` 子目录），属正常运行方式，不是残留垃圾。

## 数据存放位置

安装版与便携版**共享同一个数据目录** `%LOCALAPPDATA%\CcfReminderTray\`（设置、
提醒状态、数据缓存、手动修正 `overrides.json` 及其损坏备份 `*.corrupt-*.bak`）。
因此：在任一版本里改的设置与修正对另一版本同样生效；**卸载安装版时若选择“删除个人数据”，
该目录被整个删除后，便携版同样丢失全部手动修正与备份（无法恢复），下次运行回到默认设置
并重新下载数据**。
开机启动项（HKCU Run 的 `CcfReminderTray` 值）全系统只有一个，指向你最后**明确勾选
“开机启动”**的那份 exe。只保存通知或阈值设置不会改动它；在一份程序的设置里它指向
另一份时，界面会提示“另一位置已有启动项”，此时取消勾选不会删除该项——切换指向须在
你希望启动的那份程序里明确勾选“开机启动”并保存，清除该项须在对应那份程序里取消勾选。
卸载安装版只在该值恰好指向安装版时才清除它。

该目录内容：

- `settings.json` — 通知开关、阈值档位（不含任何密钥）；
- `reminder-state.json` — 已提醒档位与当日汇总日期；
- `overrides.json` — 你手动修正的截止时间（在“查看全部”里操作；含修正依据、来源与
  修正时间，用法见“手动修正截止时间”一节）。若该文件损坏，程序会醒目告警、按上游
  时间运行并阻止覆盖，你可在详情窗选择“备份损坏文件并重新初始化”（先把损坏文件
  **复制**留证为 `*.corrupt-*.bak`，再重建空表；原件在写入成功前不会被替换）；
- `cache\snapshot-v2.json` — 最近一次有效数据快照缓存（离线时回退使用），即
  `%LOCALAPPDATA%\CcfReminderTray\cache\snapshot-v2.json`。

## 故障排查

- 看不到通知横幅：检查 Windows“设置 → 系统 → 通知”已开启、“请勿打扰”已关闭；横幅可能已自动收进通知中心。
- 数据不更新：托盘菜单 → “立即刷新”；源站不可用时应用继续使用最近缓存并显示其更新时间。
- 反馈问题：请附上 `%LOCALAPPDATA%\CcfReminderTray\` 下的文件名清单与现象描述（注意其中不含密钥）。
